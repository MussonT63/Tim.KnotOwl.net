1. New Change
    Applications \ Change Management \ New Change
  2. Save (you may have to go find your CRQ now...)
  3. Requested For
    Quick Action box \ Requested For \ Last Name (Case sensitive), Enter, Ok, Yes
  4. Template (type "cmp", autocompletes, down arrow, enter)
    Server IMAC-NGDI \ Server IMAC - CMP Server Deployment \ Select
  5. Update Summary to make it unique/recognizable
    prefix with : //-:: 
  6. Coordinator Group*+ \ Change Coordinator+
    "CID Hosting Automation" \ Select
  7. Manager Group*+ \ Change Manager+
    "CID Hosting Automation" \ Select
  8. Next Stage button (go back to Change Console to refresh)
    Takes a LONG time to complete, and ends up in Plan & Schedule phase
  9. Next Stage to move to Implement Status (Implementation In Progress)
    "Scheduled Start Date+", OK
    "Scheduled End Date+", later date, OK, Save (ok if error)
    Next Stage again to actually move it to Implement...
    Tasks remain in Pending state.
  10. Update Tasks with eMorpheus Calls
To end the CRQ, you can change CRQ Status to Canceled...
To set default homepage to the Change Management Console
In the Change Management Console, Functions menu, Application Preferences
  • Default Home Page = Change Management Console
  • Form/After New Save = Modify Request After Submit
